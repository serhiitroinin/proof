# proof.

A [shadcn](https://ui.shadcn.com) registry for small, local-first tools. Base UI components, one theme (Native, light and dark) and a shared signature: ink first, one accent per tool, and the motif — an ink line with an accent dot at its tip.

**Docs:** https://serhiitroinin.github.io/proof

## Install

You need a shadcn project with React 19, Tailwind v4 and a Base UI style.

1. Add the registry to `components.json`:

   ```json
   {
     "registries": {
       "@proof": "https://serhiitroinin.github.io/proof/r/{name}.json"
     }
   }
   ```

2. Add the theme:

   ```sh
   npx shadcn@latest add @proof/native
   ```

3. Add components:

   ```sh
   npx shadcn@latest add @proof/button @proof/input @proof/textarea
   ```

Each component installs its dependencies, including the theme. You get the source and can change it.

## Design

[DESIGN.md](DESIGN.md) holds the design rules: tokens, typography, layout, depth, shapes, motion, the motif and writing. It uses the [DESIGN.md format](https://github.com/google-labs-code/design.md), so coding agents can read it too.

## Develop

```sh
pnpm install
pnpm dev          # docs on http://127.0.0.1:5197
pnpm lint         # ESLint with @shadcn/lint
pnpm typecheck
pnpm contrast     # WCAG contrast check for the theme tokens
pnpm build        # registry.json, public/r and the docs site
```

- Components: `src/components/ui`. Theme: `src/styles/globals.css`.
- `registry.json` is generated by `scripts/registry.ts`. Do not edit it by hand.
- Examples: `src/docs/demos/<component>/NN-title.tsx`, one example per file.

Every push to `main` builds and deploys the docs and the registry to GitHub Pages.
